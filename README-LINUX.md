# Festival Virtual Singer — Linux/CMake port

This branch ports the application layer to native Linux.

## Dependencies (Debian/Ubuntu)

    sudo apt install build-essential cmake libwxgtk3.2-dev libasound2-dev festival festvox-kallpc16k

A Festival voice compatible with the voice name stored in your song is also required.

## Build

    cmake -S . -B build -DCMAKE_BUILD_TYPE=Release
    cmake --build build -j
    ./build/FestivalVirtualSinger

or:

    ./build-linux.sh

## What changed

* Visual Studio project replaced by CMake for Linux builds.
* bundled Windows wxWidgets libraries are not used; CMake uses the system wxWidgets.
* WinMM sample engine replaced with ALSA.
* WinMM tone preview replaced with ALSA.
* FestivalTTSCOM/COM bridge replaced with the native Linux `festival` executable.
* Win32-only executable/resource/runtime files are not needed for the Linux build.
* application models, piano rolls, slicer, WAV parser/editor and offline renderer remain the original project code.

## Notes

The repository still contains the historical Windows runtime and Visual Studio files so that the original source history is preserved. CMake deliberately ignores them.

The Linux Festival bridge executes the Scheme generated by the existing song model. Festival voice packages differ by distribution, so select/install a voice whose Festival function matches the application's configured voice.
